# crc-c

Универсальная библиотека CRC32 (IEEE 802.3 / ISO-HDLC: полином 0xEDB88320 отражённый,
init = 0xFFFFFFFF, xorout = 0xFFFFFFFF, рефлексии входа/выхода).

## Реализация

API: `uint32_t crc32__ieee(uint8_t const* const data, size_t const len);`

Реализация выбирается на этапе компиляции в `crc32.h`:

- Если определён `__ZEPHYR__` — `crc32__ieee()` раскрывается макросом в
  `crc32_ieee()` из подсистемы CRC Zephyr (`<zephyr/sys/crc.h>`, `CONFIG_CRC=y`),
  без накладных расходов.
- Иначе (host-сборка, тесты) — собственная табличная реализация из `crc32.c`
  (статическая таблица 256 значений, побайтное вычисление).

Обе реализации дают побитово идентичный результат.
Для `NULL` или `len == 0` возвращается 0.

## Сборка

В составе Zephyr-приложения подключается через `add_subdirectory` в `src/lib/CMakeLists.txt`.
